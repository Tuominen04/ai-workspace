# Security

Principles

Local-first

Rootless

Explicit permissions

Read-only by default

No hidden services

No automatic writes

No telemetry

No cloud dependency

Every permission must be visible.

Every write operation must require user approval.

Projects are isolated.

Base is shared.

Nothing else.

## Reporting a vulnerability

Please report security problems privately, not as a public issue: on GitHub, **Security** →
**Report a vulnerability** ([new report](https://github.com/Tuominen04/ai-workspace/security/advisories/new)).
Say what you found, how to reproduce it, and which version (`rpm -q ai-workspace`). You get an
answer there; a fix is released before the problem is made public.

Supported versions: the latest 1.x release.
